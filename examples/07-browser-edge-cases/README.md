# 07 Browser Edge Cases

Use these examples for browser behavior that standard selectors do not cover.

- [iframe-and-shadow-dom.js](iframe-and-shadow-dom.js) - switch into iframes and open shadow roots.
- [tabs-alerts-hover.js](tabs-alerts-hover.js) - handle new tabs/windows, native alerts, and hover menus.
- [switch-to-tab-by-url.js](switch-to-tab-by-url.js) - select a new tab by matching a URL fragment instead of relying on tab order.
- [canvas-coordinate-interaction.js](canvas-coordinate-interaction.js) - interact with canvas content that is not represented by DOM child elements.
- [state-and-popups.js](state-and-popups.js) - manage cookies, storage, consent banners, and optional modals.
