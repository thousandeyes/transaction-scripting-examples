# 05 Auth And MFA

Use these examples for flows that need credentials beyond a simple password.

- [totp-login.js](totp-login.js) - generate and submit a time-based one-time password.
- [math-captcha.js](math-captcha.js) - solve simple math captchas when the app intentionally exposes the challenge text.

For standalone HTTP API checks with Basic, Bearer, OAuth, headers, bodies, assertions, variables, client certificates, SSL verification controls, or proxy settings, use a ThousandEyes API test instead of a transaction-script example.
